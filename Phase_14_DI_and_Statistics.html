📐 Formula Vault

📐 Pie Chart Conversion
Central Angle (°) = (%) × 3.6 % = Central Angle / 3.6 360° = 100% | 1% = 3.6°
When to use: Any pie chart angle-to-value conversion
⚡ Shortcut: Sector of 54°: 54/3.6=15%. Sector of 20%: 20×3.6=72°.
🚨 Trap: Always check whether question asks for angle OR percentage — students often give the wrong form.
📐 Empirical Relation
Mode = 3(Median) - 2(Mean)
When to use: Moderately skewed unimodal distribution where one of Mean/Median/Mode is missing
⚡ Shortcut: Mean=24, Median=26: Mode=3(26)-2(24)=78-48=30.
🚨 Trap: This formula is for MODERATELY SKEWED distributions. For symmetrical: Mean=Median=Mode. Don't use empirical for perfectly symmetrical data.
📐 Variance & Standard Deviation
Variance = σ² = Σ(xᵢ - x̄)² / N SD = σ = √Variance SD of (ax + b) = |a| × σ (b doesn't affect spread)
When to use: Measuring spread/dispersion of data set
⚡ Shortcut: If each observation increased by k: Mean increases by k, SD unchanged. If each multiplied by k: both Mean and SD multiply by k.
🚨 Trap: Adding a constant to all data: Mean changes but SD does NOT change. Multiplying all: both change.

⚡ Speed Shortcuts

⚡ DI Fast Reading Protocol (6 Steps)
1. Title: what data represents. 2. Units: lakhs? crores? thousands? 3. Time axis: years/months. 4. Read specific question FIRST. 5. Identify only needed rows/columns. 6. Estimate → confirm with single calculation.
⚡ Bar Chart Comparison Shortcut
For ratio questions between two bars: read both values, divide. For % change: (New-Old)/Old×100. Never calculate full values if ratio is asked.
⚡ Standard Deviation Constants
Data: {2,4,6,8,10}. Mean=6. Adding 5 to each: {7,9,11,13,15}. New Mean=11. SD unchanged. Multiplying by 2: {4,8,12,16,20}. New Mean=12. New SD=2×old SD.

🚨 SSC Exam Trap Library

🚨 DI Unit Scale Trap Error-R
Data table says 'Sales in thousands'. Value shown=45. Actual=45,000. Missing the unit multiplier is the most common DI error.
🚨 Pie Chart % vs Angle Trap Error-R
Question asks 'what % is sector A?', but you calculate the angle. Or vice versa. Always check: does the question want degrees or percentage?
🚨 SD Unaffected by Shift Trap Error-C
Adding same constant to all data doesn't change SD. Students think SD increases when mean increases — wrong! Only multiplication changes SD.

In a moderately skewed distribution, Mean=30 and Median=33. Find Mode.
Hint: Empirical formula: Mode = 3×Median - 2×Mean
Answer: Mode = 3(Median) - 2(Mean) = 3(33) - 2(30) = 99 - 60 = 39.

Level A: Foundation
SD of data set is 6. If each observation is multiplied by 3, find new SD and new Variance.
Hint: Multiplying all by k: SD multiplies by k, Variance multiplies by k².
Answer: New SD = 3×6 = 18. New Variance = 18² = 324.

Hint: Convert angle to %: angle/3.6. Then find % of total.
Answer: % = 54/3.6 = 15%. Amount = 15% of 5,00,000 = ₹75,000.

If mean of 5 numbers is 12 and one number 8 is replaced by 18, find new mean.
Hint: New sum = old sum - replaced value + new value
Answer: Old sum=60. New sum=60-8+18=70. New mean=70/5=14.

Answer: Sorted: 38,43,45,49,52,56,58,61,67,71. 10 values, median=(5th+6th)/2=(52+56)/2=54.

🏆 SSC PYQ Lab

🔐 Integrity Rule: Actual PYQ tabhi label karo jab year/shift verified ho. Otherwise: "PYQ-style" label use karo.
PYQ-style • SSC CGL Tier-1 DI
In a bar chart, Company A's profit in 2022=₹45L and in 2023=₹60L. Find % increase.
% increase = (60-45)/45 × 100 = 15/45 × 100 = 33.33%.
PYQ-style • SSC CHSL Pattern
Mean of 9 consecutive integers is 25. What is the sum of largest and smallest integers?
Mean=25 = middle(5th) integer. Smallest=25-4=21, Largest=25+4=29. Sum=50.
