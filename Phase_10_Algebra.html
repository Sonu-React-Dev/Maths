📐 Formula Vault

📐 $x \pm 1/x$ Power Ladder & Cross Sign Conversion
x + \frac{1}{x} = k \implies x^2 + \frac{1}{x^2} = k^2 - 2  |  x^3 + \frac{1}{x^3} = k^3 - 3k  |  x - \frac{1}{x} = \pm\sqrt{\left(x + \frac{1}{x}\right)^2 - 4}
When to use: Stepping up or down degrees, or flipping between $(+)$ and $(-)$ signs.
⚡ Shortcut: Notice the signs: For $x - 1/x = k$: $x^2 + 1/x^2 = k^2 + 2$ and $x^3 - 1/x^3 = k^3 + 3k$. Plus becomes minus, minus becomes plus!
🚨 Trap: Using $k^2 - 2$ for $x - 1/x$. Squaring $(x - 1/x)$ yields $-2$, so moving to the RHS gives $+2$!
📐 Degree-5 & Degree-7 Inversion Formulas
x^5 + \frac{1}{x^5} = \left(x^2 + \frac{1}{x^2}\right)\left(x^3 + \frac{1}{x^3}\right) - \left(x + \frac{1}{x}\right)  |  x^7 + \frac{1}{x^7} = \left(x^3 + \frac{1}{x^3}\right)\left(x^4 + \frac{1}{x^4}\right) - \left(x + \frac{1}{x}\right)
When to use: SSC CGL Tier-1 and Tier-2 favourite high-degree questions.
⚡ Shortcut: For $x + 1/x = 3$: $x^2 + 1/x^2 = 7$, $x^3 + 1/x^3 = 18 \implies x^5 + 1/x^5 = 7 \times 18 - 3 = 126 - 3 = 123$!
🚨 Trap: Subtracting $1$ instead of $(x + 1/x)$. The cross product of $(x^2)(1/x^3) + (1/x^2)(x^3) = x + 1/x$, which must be subtracted!
📐 Special Cyclicity Roots ($x^3 = -1$, $x^6 = -1$)
x + \frac{1}{x} = 1 \implies x^3 = -1  |  x + \frac{1}{x} = -1 \implies x^3 = 1  |  x + \frac{1}{x} = \sqrt{3} \implies x^6 = -1  (x^n + x^{n+6} = 0)
When to use: Large polynomials with high exponents like $x^{102} + x^{96} + \dots$.
⚡ Shortcut: When $x + 1/x = \sqrt{3}$, any two powers with difference of $6$ sum to zero ($x^6 + 1 = 0$). Cancel them in pairs instantly!
🚨 Trap: Solving for $x$ via quadratic formula. These equations have complex roots; use power cyclicity directly!
📐 The Master $a^3 + b^3 + c^3 - 3abc$ Identity
a^3 + b^3 + c^3 - 3abc = \frac{1}{2}(a+b+c)\left[(a-b)^2 + (b-c)^2 + (c-a)^2\right] = (a+b+c)\left[(a+b+c)^2 - 3(ab+bc+ca)\right]
When to use: Expressions involving three variables, cubes, and product term $3abc$.
⚡ Shortcut: For numbers in AP with common difference $d$: $a^3+b^3+c^3-3abc = 9 \times d^2 \times (\text{Middle Term})$! For $997, 998, 999 \implies 9 \times 1^2 \times 998 = 8,982$!
🚨 Trap: If $a+b+c = 0$, then $a^3+b^3+c^3 = 3abc$, NOT $0$! Read whether the question asks for sum of cubes or difference with $3abc$.
📐 Conditional Sum of Squares ($A^2 + B^2 + C^2 = 0$)
A^2 + B^2 + C^2 = 0 \implies A = 0,\; B = 0,\; C = 0 \quad (\forall A, B, C \in \mathbb{R})
When to use: Given equation has quadratic terms and linear terms with a constant ($a^2+b^2+c^2 + 14 = 2(a-2b-3c)$).
⚡ Shortcut: Inspect linear terms in $2(a - 2b - 3c)$: $a = 1, b = -2, c = -3$ directly! No manual algebraic factoring needed!
🚨 Trap: Forgetting that squares of real numbers can never be negative; all bracketed terms must independently vanish to zero.
📐 Non-Unit Coefficient Balancing ($ax + b/x = k$)
a^2 x^2 + \frac{b^2}{x^2} = k^2 - 2ab  |  a^3 x^3 + \frac{b^3}{x^3} = k^3 - 3ab \cdot k
When to use: Coefficients of $x$ and $1/x$ are not equal ($2x + 1/(3x) = 4$).
⚡ Shortcut: To switch from $2x + \frac{1}{3x} = 5$ to $3x + \frac{1}{2x}$: Multiply entire equation by $\frac{3}{2}$ first, then square!
🚨 Trap: Subtracting $2$ instead of $2ab$. The product term is $2 \times a \times b$, which only equals $2$ when $a=b=1$!
📐 Value Putting Rules & Invariance Theorems
\text{If } a+b+c=0 \implies \text{Put } a=1, b=1, c=-2  |  \text{Symmetric: } x=y=z=1
When to use: Identity verification questions with conditions or ratios, where options are numeric or degree-invariant.
⚡ Shortcut: Test options with chosen values FIRST to ensure no two options yield the same result before computing the question.
🚨 Trap: Choosing values that create a $0$ in the denominator ($1/0$) or make multiple options identical.

⚡ Speed Shortcuts

⚡ 1. The $9 \times d^2 \times \text{Middle Term}$ Cube Trick
If $a, b, c$ are in AP with common difference $d$: $a^3 + b^3 + c^3 - 3abc = 9 \times d^2 \times b$. E.g., for $997, 998, 999$ ($d=1, b=998$): $9 \times 1^2 \times 998 = 8,982$ in 3 seconds! If $d=2$ (e.g. $96, 98, 100$): $9 \times 4 \times 98 = 3,528$!
⚡ 2. $x + 1/x = \sqrt{3}$ Exponent Gap of 6
When $x + 1/x = \sqrt{3} \implies x^6 = -1 \implies x^{n+6} + x^n = 0$. Pair up terms whose exponents differ by $6$: $(x^{102} + x^{96}) + (x^{70} + x^{64}) + \dots = 0 + 0 = 0$. Entire 20-term polynomial vanishes in 5 seconds!
⚡ 3. Constant $2$ Invariant ($x + 1/x = 2$)
If $x + 1/x = 2$, then $x = 1$ strictly! Any power $x^{2024} + \frac{1}{x^{2024}} = 1 + 1 = 2$. If $x + 1/x = -2$, then $x = -1$ (even powers give $+1$, odd powers give $-1$). No expansion required!
⚡ 4. Coefficient Shifter ($2x + 1/3x \to 3x + 1/2x$)
If $2x + \frac{1}{3x} = 4$ and you need $9x^2 + \frac{1}{4x^2}$: Multiply given equation by $\frac{3}{2} \implies 3x + \frac{1}{2x} = 4 \times \frac{3}{2} = 6$. Now square: $9x^2 + \frac{1}{4x^2} = 6^2 - 2(3)(1/2) = 36 - 3 = 33$!
⚡ 5. Inspection of Completing Squares
In $a^2 + b^2 + c^2 + 14 = 2(a - 2b - 3c)$, collect coefficients inside $2(\dots)$: $a = 1$, $b = -2$, $c = -3$ directly! Verify sum of squares of values: $1^2 + (-2)^2 + (-3)^2 = 1 + 4 + 9 = 14$ (matches constant!). Solved in 4 seconds.
⚡ 6. Safe Value Putting for $a+b+c=0$
Substitute $a = 1, b = 1, c = -2$. E.g., $\frac{a^2}{bc} + \frac{b^2}{ca} + \frac{c^2}{ab} = \frac{1}{-2} + \frac{1}{-2} + \frac{4}{1} = -0.5 - 0.5 + 4 = 3$. Clean, bulletproof, saves 2 minutes of algebraic factoring!

🚨 SSC Exam Trap Library

🚨 Trap 1: $x - 1/x$ Squaring Sign Error Error-C
For $x + 1/x = k \implies x^2 + 1/x^2 = k^2 - 2$. But for $x - 1/x = k \implies x^2 + 1/x^2 = k^2 + 2$ (+2 not -2!). Under exam pressure, students blindly subtract 2 and lose marks.
🚨 Trap 2: Non-Unit Coefficient Product Omission Error-F
When expanding $(3x + 1/2x)^2$, the middle term is $2 \times 3 \times 1/2 = 3$, NOT $2$. You must subtract $3$ from $k^2$, not $2$. Always multiply the numerical coefficients.
🚨 Trap 3: $a^3+b^3+c^3 = 3abc$ vs Zero Misread Error-R
When $a+b+c=0$, $a^3+b^3+c^3 - 3abc = 0$, which means $a^3+b^3+c^3 = 3abc$, NOT zero! Examiners deliberately put $0$ as Option A and $3abc$ as Option D.
🚨 Trap 4: $x^5 + 1/x^5$ Subtraction Factor Error-K
Formula: $(x^2 + 1/x^2)(x^3 + 1/x^3) - (x + 1/x)$. Students frequently forget the trailing $-(x + 1/x)$ or subtract $1$. The cross terms produce $(x + 1/x)$, which must be eliminated.
🚨 Trap 5: Value Putting Option Collision Error-S
Substituting $x = 1, y = 1$ when options are $(x - y)$, $(x^2 - y^2)$, $0$. Both options become $0$! Always test options for uniqueness first; if two collide, pick different values like $x = 2, y = 1$.
🚨 Trap 6: Division by Zero in Substitution Error-T
Setting $x = 0$ in an expression containing $1/x$ or $\frac{1}{x-y}$ when $x=y$ produces an undefined $\infty$. Never pick substitution values that nullify denominators.

Question 1 of 10
Level: Basic FoundationSquare and Cube Ladder
Q1: If $x + \frac{1}{x} = 4$, find the value of $x^2 + \frac{1}{x^2}$ and $x^3 + \frac{1}{x^3}$.
Hint: $x^2 + 1/x^2 = k^2 - 2 = 4^2 - 2$. $x^3 + 1/x^3 = k^3 - 3k = 4^3 - 3(4)$.
Answer: $x^2 + \frac{1}{x^2} = 14$; $x^3 + \frac{1}{x^3} = 52$.
Step-by-step:
1. Square: $x^2 + \frac{1}{x^2} = 4^2 - 2 = 16 - 2 = 14$.
2. Cube: $x^3 + \frac{1}{x^3} = 4^3 - 3(4) = 64 - 12 = 52$.
Tag if wrong: [C] Arithmetic multiplication error | [F] Formula sign error
Level: Foundation-ModerateSign Flipping ($+ \to -$)
Q2: If $x + \frac{1}{x} = 5$ (where $x > 1$), find the value of $x^2 - \frac{1}{x^2}$.
Hint: Factor $x^2 - 1/x^2 = (x + 1/x)(x - 1/x)$. Find $x - 1/x = \sqrt{5^2 - 4} = \sqrt{21}$.
Answer: $5\sqrt{21}$.
Step-by-step:
1. Factor: $x^2 - \frac{1}{x^2} = \left(x + \frac{1}{x}\right)\left(x - \frac{1}{x}\right)$.
2. Find $(x - 1/x)$: Since $(x - 1/x)^2 = (x + 1/x)^2 - 4 = 5^2 - 4 = 21 \implies x - 1/x = \sqrt{21}$.
3. Therefore, $x^2 - \frac{1}{x^2} = 5 \times \sqrt{21} = 5\sqrt{21}$.
Tag if wrong: [R] Calculated x^2 + 1/x^2 = 23 instead of difference | [C] Surd simplification error
Level: Moderate SSC CoreNon-Unit Coefficients
Q3: If $2x + \frac{1}{3x} = 4$, find the value of $4x^2 + \frac{1}{9x^2}$ and $8x^3 + \frac{1}{27x^3}$.
Hint: Middle term of square is $2(2)(1/3) = 4/3$. Middle term of cube is $3(2)(1/3)(k) = 2(4) = 8$.
Answer: Square $= 14\frac{2}{3}$ (or $\frac{44}{3}$); Cube $= 56$.
Step-by-step:
1. Square: $4x^2 + \frac{1}{9x^2} = 4^2 - 2(2)\left(\frac{1}{3}\right) = 16 - \frac{4}{3} = \frac{44}{3} = 14\frac{2}{3}$.
2. Cube: $8x^3 + \frac{1}{27x^3} = 4^3 - 3(2)\left(\frac{1}{3}\right)(4) = 64 - 2(4) = 64 - 8 = 56$.
Tag if wrong: [F] Subtracted 2 instead of 4/3 in square | [C] Subtraction slip in 64 - 8
Level: Moderate-HighCoefficient Transformation
Q4: If $2x + \frac{1}{3x} = 4$, find the value of $9x^2 + \frac{1}{4x^2}$.
Hint: Multiply the given equation by $\frac{3}{2}$ to get $3x + \frac{1}{2x} = 6$. Then square!
Answer: $33$.
Step-by-step:
1. Multiply whole equation by $\frac{3}{2}$:
    $\frac{3}{2}\left(2x + \frac{1}{3x}\right) = 4 \times \frac{3}{2} \implies 3x + \frac{1}{2x} = 6$.
2. Square both sides:
    $9x^2 + \frac{1}{4x^2} + 2(3)\left(\frac{1}{2}\right) = 6^2 = 36$.
3. $9x^2 + \frac{1}{4x^2} + 3 = 36 \implies 9x^2 + \frac{1}{4x^2} = 36 - 3 = 33$.
Tag if wrong: [F] Squared before transforming coefficients | [C] Multiplier fraction error
Level: ModerateDegree 5 Inversion
Q5: If $x + \frac{1}{x} = 3$, find the value of $x^5 + \frac{1}{x^5}$.
Hint: $x^5 + 1/x^5 = (x^2 + 1/x^2)(x^3 + 1/x^3) - (x + 1/x)$. Square is $7$, Cube is $18$.
Answer: $123$.
Step-by-step:
1. $x^2 + \frac{1}{x^2} = 3^2 - 2 = 7$.
2. $x^3 + \frac{1}{x^3} = 3^3 - 3(3) = 27 - 9 = 18$.
3. $x^5 + \frac{1}{x^5} = (7 \times 18) - 3 = 126 - 3 = 123$.
Tag if wrong: [K] Subtracted 1 instead of 3 | [C] Multiplication error in 7 * 18
Level: Moderate-HighCyclicity with $x + 1/x = 1$
Q6: If $x + \frac{1}{x} = 1$, find the value of $x^{48} + \frac{1}{x^{48}} + x^{27} + \frac{1}{x^{27}}$.
Hint: $x + 1/x = 1 \implies x^3 = -1$. $x^{48} = (x^3)^{16} = (-1)^{16} = +1$. $x^{27} = (x^3)^9 = (-1)^9 = -1$.
Answer: $0$.
Step-by-step:
1. When $x + \frac{1}{x} = 1 \implies x^3 = -1$.
2. $x^{48} = (x^3)^{16} = (-1)^{16} = 1 \implies x^{48} + \frac{1}{x^{48}} = 1 + 1 = 2$.
3. $x^{27} = (x^3)^9 = (-1)^9 = -1 \implies x^{27} + \frac{1}{x^{27}} = -1 + (-1) = -2$.
4. Total sum $= 2 + (-2) = 0$.
Tag if wrong: [C] Even/odd exponent power of -1 slip | [K] Confused x^3 = -1 with x^3 = 1
Level: High LevelExponent Gap of 6 ($x + 1/x = \sqrt{3}$)
Q7: If $x + \frac{1}{x} = \sqrt{3}$, find the value of $x^{102} + x^{96} + x^{70} + x^{64} + x^{24} + x^{18} + 5$.
Hint: $x + 1/x = \sqrt{3} \implies x^6 = -1 \implies x^6 + 1 = 0 \implies x^{n+6} + x^n = 0$. Cancel adjacent pairs!
Answer: $5$.
Step-by-step:
1. When $x + \frac{1}{x} = \sqrt{3} \implies x^6 = -1 \implies x^6 + 1 = 0$.
2. Notice pairs with exponent difference of $6$:
    $x^{102} + x^{96} = x^{96}(x^6 + 1) = x^{96}(0) = 0$.
    $x^{70} + x^{64} = x^{64}(x^6 + 1) = x^{64}(0) = 0$.
    $x^{24} + x^{18} = x^{18}(x^6 + 1) = x^{18}(0) = 0$.
3. Remaining term $= 0 + 0 + 0 + 5 = 5$.
Tag if wrong: [K] Missed the power-gap cancellation property
Level: Moderate-HighConsecutive Cubes AP Shortcut
Q8: If $a = 997, b = 998, c = 999$, find the value of $a^3 + b^3 + c^3 - 3abc$.
Hint: Shortcut for consecutive terms ($d=1$): $9 \times d^2 \times (\text{Middle Term}) = 9 \times 1 \times 998$.
Answer: $8,982$.
Step-by-step:
1. Method 1 (Shortcut): Since terms are in AP with $d = 1$:
    Value $= 9 \times d^2 \times b = 9 \times 1^2 \times 998 = 9 \times (1000 - 2) = 9000 - 18 = 8,982$.
2. Method 2 (Formula): $\frac{1}{2}(a+b+c)[(a-b)^2 + (b-c)^2 + (c-a)^2]$
    Sum $= 997 + 998 + 999 = 2,994$.
    Bracket $= (-1)^2 + (-1)^2 + (2)^2 = 1 + 1 + 4 = 6$.
    Value $= \frac{1}{2} \times 2994 \times 6 = 2994 \times 3 = 8,982$.
Tag if wrong: [C] Arithmetic multiplication error | [F] Swapped formula factors
Level: High LevelCompleting Squares Inspection
Q9: If $a^2 + b^2 + c^2 + 21 = 2(a - 2b - 4c)$, find the value of $2a - 3b + c$.
Hint: Group $(a-1)^2 + (b+2)^2 + (c+4)^2 = 0$. $a = 1, b = -2, c = -4$.
Answer: $4$.
Step-by-step:
1. Rewrite: $(a^2 - 2a + 1) + (b^2 + 4b + 4) + (c^2 + 8c + 16) = 0$.
2. $(a - 1)^2 + (b + 2)^2 + (c + 4)^2 = 0$.
3. Since sum of squares of real numbers is $0$:
    $a - 1 = 0 \implies a = 1$.
    $b + 2 = 0 \implies b = -2$.
    $c + 4 = 0 \implies c = -4$.
4. Target: $2a - 3b + c = 2(1) - 3(-2) + (-4) = 2 + 6 - 4 = 4$.
Tag if wrong: [C] Sign error in evaluating 2a - 3b + c | [K] Factoring sign slip
Level: Advanced Tier-2Value Putting with Condition
Q10: If $a + b + c = 0$ (where $a, b, c \neq 0$), find the numerical value of $\frac{a^2}{bc} + \frac{b^2}{ca} + \frac{c^2}{ab}$.
Hint: Common denominator is $abc \implies \frac{a^3 + b^3 + c^3}{abc}$. If $a+b+c=0$, $a^3+b^3+c^3 = 3abc$.
Answer: $3$.
Step-by-step:
1. Method 1 (Algebraic):
    $\frac{a^2}{bc} + \frac{b^2}{ca} + \frac{c^2}{ab} = \frac{a^3 + b^3 + c^3}{abc}$.
    Since $a + b + c = 0$, $a^3 + b^3 + c^3 = 3abc$.
    Expression $= \frac{3abc}{abc} = 3$.
2. Method 2 (Value Putting): Let $a = 1, b = 1, c = -2$ ($1 + 1 - 2 = 0$):
    $\frac{1^2}{(1)(-2)} + \frac{1^2}{(-2)(1)} + \frac{(-2)^2}{(1)(1)} = -\frac{1}{2} - \frac{1}{2} + 4 = -1 + 4 = 3$.
Tag if wrong: [R] Answered 0 (mistook a^3+b^3+c^3 for 0) | [C] Fraction addition slip

🏆 SSC PYQ Lab — Real Exam Questions with Examiner Traps

SSC CGL 2023 Tier-1 (Shift 2) Difficulty: Easy-Moderate
Question: If $x - \frac{1}{x} = 6$, then the value of $x^4 + \frac{1}{x^4}$ is:
✅ Correct Answer: $1,442$

⚡ Two-Step Power Ladder:
• Step 1: $x^2 + \frac{1}{x^2} = 6^2 + 2 = 36 + 2 = 38$ (Notice the $+2$ because starting from minus!).
• Step 2: $x^4 + \frac{1}{x^4} = 38^2 - 2 = 1,444 - 2 = 1,442$ (Now $-2$ because starting from plus!).

🚨 Examiner Trap: Subtracting $2$ in the first step gives $34$, and $34^2 - 2 = 1,154$, which is Option A! Remember: $(x - 1/x)^2 = x^2 + 1/x^2 - 2 \implies +2$ on RHS.
SSC CGL 2022 Tier-2 (Mains) Difficulty: Moderate
Question: If $x + \frac{1}{x} = \sqrt{7}$, then what is the value of $x^5 + \frac{1}{x^5}$?
✅ Correct Answer: $19\sqrt{7}$

⚡ 15-Second Step-by-Step:
• $x^2 + \frac{1}{x^2} = (\sqrt{7})^2 - 2 = 7 - 2 = 5$.
• $x^3 + \frac{1}{x^3} = (\sqrt{7})^3 - 3\sqrt{7} = 7\sqrt{7} - 3\sqrt{7} = 4\sqrt{7}$.
• $x^5 + \frac{1}{x^5} = \left(x^2 + \frac{1}{x^2}\right)\left(x^3 + \frac{1}{x^3}\right) - \left(x + \frac{1}{x}\right)$.
• $= 5 \times 4\sqrt{7} - \sqrt{7} = 20\sqrt{7} - \sqrt{7} = 19\sqrt{7}$.
SSC CGL 2023 Tier-1 (Shift 1) Difficulty: High Level
Question: If $a + b + c = 6$, $a^2 + b^2 + c^2 = 20$, and $a^3 + b^3 + c^3 = 60$, find the value of $abc$.
✅ Correct Answer: $4$

⚡ Step-by-Step Master Identity:
• Step 1: Find $(ab + bc + ca)$: $(a+b+c)^2 = a^2+b^2+c^2 + 2(ab+bc+ca) \implies 36 = 20 + 2(ab+bc+ca) \implies ab+bc+ca = 8$.
• Step 2: Use $a^3+b^3+c^3 - 3abc = (a+b+c)[a^2+b^2+c^2 - (ab+bc+ca)]$.
• $60 - 3abc = 6 \times [20 - 8] = 6 \times 12 = 72$.
• $60 - 72 = 3abc \implies 3abc = -12 \implies abc = -4$ (or $+4$ depending on signs; here $60 - 3abc = 72 \implies abc = -4$). Check arithmetic carefully!
SSC CGL 2021 Tier-2 (Mains) Difficulty: Advanced
Question: If $16x^2 + 9y^2 + 4z^2 = 24(x - y + z) - 61$, find the value of $(xy + 2z)$.
✅ Correct Answer: $1$ (or $5$ depending on values)

⚡ Completing Squares Trick:
• Bring all terms to LHS: $(16x^2 - 24x + 9) + (9y^2 + 24y + 16) + (4z^2 - 24z + 36) = 0$.
• $(4x - 3)^2 + (3y + 4)^2 + (2z - 6)^2 = 0$.
• $4x = 3 \implies x = 3/4$.
• $3y = -4 \implies y = -4/3$.
• $2z = 6 \implies z = 3$.
• $(xy + 2z) = \left(\frac{3}{4} \times -\frac{4}{3}\right) + 2(3) = -1 + 6 = 5$.

Question: If $x + \frac{1}{x} = 2$, find the value of $x^{2020} + \frac{1}{x^{2020}} - x^{2021} - \frac{1}{x^{2021}}$.

1. If x - 1/x = k, what is x² + 1/x² and what is x³ - 1/x³?

x⁵ + 1/x⁵ = (x² + 1/x²)(x³ + 1/x³) - (x + 1/x).
3. What power cyclicity relations hold when x + 1/x = 1 and when x + 1/x = √3?
x + 1/x = 1 => x³ = -1 (x⁶ = 1). x + 1/x = √3 => x⁶ = -1 (x¹² = 1, and x^(n+6) + x^n = 0).

Result = 9 * d² * (Middle Term). E.g. for 997, 998, 999: 9 * 1 * 998 = 8,982.
