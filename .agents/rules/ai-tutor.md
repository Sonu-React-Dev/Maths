   - `F` - Formula

   - `R` - Reading / misunderstanding
   - `T` - Time / slow method
4. **Integrity Rule for PYQs**: Only label verified exam questions as SSC PYQ; otherwise label them `PYQ-style`.

6. **Active Recall & Spaced Repetition**: Hide formulas first, prompt student recall, then verify.
