Day 85 Fundamental Pythagorean Identities

📐 Formula Vault & Core Logic

Pythagorean Identities
sin²θ + cos²θ = 1 | sec²θ - tan²θ = 1 | cosec²θ - cot²θ = 1
💡 secθ + tanθ = x → secθ - tanθ = 1/x
Maxima & Minima of a sinθ + b cosθ
Maximum = +√(a² + b²) | Minimum = -√(a² + b²)
💡 Direct formula for linear combination
30°-60°-90° Triangle Ratio
Opposite 30° : Opposite 60° : Hypotenuse (90°) = 1 : √3 : 2
💡 If side opp 30° is h → opp 60° is h√3
45°-45°-90° Triangle Ratio
Base : Height : Hypotenuse = 1 : 1 : √2
💡 Equal legs

⚡ Reciprocal Sec-Tan Trick

If secθ + tanθ = 5 → secθ - tanθ = 1/5 = 0.2 → 2secθ = 5.2 → secθ = 2.6.

💡 Solved Foundation Examples

Sec-Tan Reciprocal
Q: If secθ + tanθ = 3, find the value of sinθ.
Solution:
1. secθ - tanθ = 1/3.
2. Adding: 2secθ = 3 + 1/3 = 10/3 → secθ = 5/3 (Hypotenuse/Base).
3. Triangle: Base = 3, Hyp = 5 → Perpendicular = 4.
4. sinθ = Perpendicular / Hypotenuse = 4/5.
Height & Distance Ratio
Q: From top of a 50 m high tower, angle of depression of a car on ground is 30°. Find distance of car from base of tower.
Solution:
In 30°-60°-90° triangle, side opp 30° = 50 m.
Distance (side opp 60°) = 50 × √3 = 50√3 m ≈ 86.6 m.
