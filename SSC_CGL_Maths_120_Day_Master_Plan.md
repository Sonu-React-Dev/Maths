# 1. Course Objective

The objective is not simply to "finish chapters".

By the end of the course, the student should be able to:

- Understand Maths from zero level.
- Identify the concept behind an SSC question.
- Select the shortest valid method.
- Remember formulas through logic rather than blind memorization.
- Perform common calculations mentally.
- Solve standard SSC PYQs.
- Solve mixed-concept questions.
- Work under a time limit.
- Detect and correct recurring mistakes.
- Revise the entire syllabus systematically.
- Transition from learning mode to exam mode.

## Target Exams

The syllabus is primarily designed around SSC Quantitative Aptitude and has substantial overlap with:

- SSC CGL
- SSC CHSL
- SSC CPO
- SSC MTS
- SSC GD
- Other common government-exam quantitative sections

**Exam-specific notifications and patterns can change. Always verify the current official notification when preparing for a particular exam.**

## Teaching Rule

We will not jump directly to difficult questions.

Example:

```text

Level 1 → Direct percentage
Level 2 → Percentage increase/decrease

```

The difficulty increases only after the previous level becomes comfortable.

- Population
- Salary

## Core Formula

```text
Percentage = Part / Whole × 100
```

## High-Value Fraction Table

Learn gradually:

| Fraction | Percentage |
|---|---:|
| 1/2 | 50% |
| 1/3 | 33.33% |
| 1/4 | 25% |
| 1/5 | 20% |
| 1/6 | 16.67% |
| 1/8 | 12.5% |
| 1/10 | 10% |
| 1/20 | 5% |
| 1/25 | 4% |
| 1/40 | 2.5% |
| 1/50 | 2% |

## Successive Change

For increases/decreases:

```text
Net % change
= a + b + ab/100
```

Use signs carefully.

Example:

```text
+20%, −10%

= 20 − 10 + (20×−10)/100
= 8% increase
```

## Reverse Percentage

If a final value is known after an increase/decrease, work backward instead of blindly subtracting the percentage.

- Sum from average
- Average from sum
- New member added
- Member removed
- Replacement
- Combined average
- Weighted average

## Core Formula

```text
Average = Total / Number of items
```

Therefore:

```text
Total = Average × Number
```

For replacement questions:

```text
Change in total
= Change in average × Number of items
```

This is often much faster than rebuilding the whole sum.

## Core Formulas

```text
Profit = SP − CP
Loss = CP − SP

Profit% = Profit/CP × 100
Loss% = Loss/CP × 100

Discount = MP − SP
Discount% = Discount/MP × 100
```

## Successive Discount

For discounts a and b:

```text
Net discount
= a + b − ab/100
```

## Important Warning

Profit/loss percentage is normally calculated on **CP**, while discount percentage is calculated on **MP**.

Always identify the base.


# 25. Short-Trick System

Short tricks are not the starting point.

Correct order:

```text
Understand
→ Solve normally
→ Identify pattern
→ Learn shortcut
→ Compare both methods
→ Use shortcut only when safe
```

## Types of Tricks We Will Build

### 1. Fraction Conversion

```text
1/2, 1/3, 1/4, 1/5...
```

### 2. Percentage Conversion

Fast recognition of common percentages.

### 3. Multiplication

Use decomposition:

```text
48 × 25
= 48 × 100 / 4
= 1200
```

### 4. Base Method

For numbers close to 100:

```text
97 × 96
= (100−3)(100−4)
= 10000−700+12
= 9312
```

### 5. Ratio Method

Convert word information into ratios before using lengthy equations.

### 6. LCM Method

Especially useful for:

- Work
- Pipes
- Some fraction-based questions

### 7. Option Elimination

When appropriate, use options to reduce calculation.

### 8. Approximation

Use only where the question/options allow it.

# 35. What the Student Does vs What the Tutor Does

## Student

The student must:

- Attend/complete the lesson.
- Solve questions.
- Attempt questions before seeing solutions.
- Maintain formula notebook.
- Maintain error notebook.
- Do daily calculation practice.
- Complete assigned PYQs.
- Take tests honestly.
- Revise.

## Tutor / ChatGPT

The tutor will:

- Explain from zero.
- Break difficult concepts into small steps.
- Give examples.
- Ask interactive questions.
- Check answers.
- Diagnose mistakes.
- Teach alternate methods.
- Introduce shortcuts at the right time.
- Generate targeted practice.
- Generate timed tests.
- Revise weak concepts.
- Track progression within the conversation.
- Increase difficulty gradually.

# 36. Rules for the Course

## Rule 1 — No Blind Memorization

Understand the reason first.

## Rule 2 — No Solution Before Attempt

Always attempt first.

## Rule 3 — Shortcut After Concept

Never build the whole preparation around tricks.

## Rule 4 — PYQ Is Mandatory

PYQs are part of learning, not an optional extra.

## Rule 5 — Accuracy Before Speed

First solve correctly.

## Rule 6 — Every Repeated Mistake Gets a Fix

If the same mistake appears repeatedly, stop and repair the concept.

## Rule 7 — Mixed Practice Is Mandatory

After learning individual chapters, mix them.

## Rule 8 — Revision Is Part of the Syllabus

A chapter without revision is not complete.

## Rule 9 — Timed Practice Starts Gradually

Do not panic about speed on Day 1.

## Rule 10 — Current Exam Pattern Must Be Verified

When preparing for a specific upcoming examination, check the latest official notification and syllabus before final exam-specific adjustments.

## The Most Important Principle

Do not measure progress only by:

> "How many chapters have I completed?"

Measure it by:

> "How many questions can I correctly recognize, approach, solve and finish within the required time?"
